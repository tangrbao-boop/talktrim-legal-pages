智剪 TalkTrim 隐私政策

生效日期：2026年10月15日。

最近更新：2026年10月16日。

运营主体：王召露（个人开发者）

支持及隐私联系：6666699999@live.com

适用范围

本政策适用于 macOS 版智剪 TalkTrim。应用导入受支持的 Final Cut Pro FCPXML 项目，准备由你审核的粗剪建议，并导出新的 FCPXML 项目。无需创建 TalkTrim 账号。

本机项目、媒体与保存

当你选择 FCPXML 文件及其引用的媒体时，TalkTrim 在本机解析项目、读取已有字幕并分析音频。原始视频、音频和完整 FCPXML 文件不作为 AI 请求内容上传；字幕文字及下述派生信息会在你同意生成时发送。导出的派生项目保存到你选择的位置，源项目不会被覆盖。

应用在本机保存普通偏好、模型和服务地址配置、文件访问书签、最近项目定位信息、建议生成历史和审核状态、运行摘要及可重新生成的音频分析缓存。历史包含建议理由等与内容有关的信息，不应视为匿名数据。应用未为项目历史设置固定自动到期时间；最近运行摘要最多保留五条，这个数量不限制项目建议历史。缓存没有应用保证的固定清除时间，系统可能清理缓存。

第三方 AI、服务地址和发送内容

第三方 AI 模型服务由你自行配置。你可以在设置的大模型管理中添加不同服务的账户、HTTPS 服务地址、模型 ID 和 API Key，并按该服务类型已实现的能力进行连接测试或刷新模型；未支持自动发现的服务需手动填写模型 ID。添加账户、发现模型或连接测试通过，不代表该账户已可用于正式粗剪。

当前正式粗剪仍使用默认生产连接的 DeepSeek 协议调用路径，默认服务地址为 https://api.deepseek.com，生成请求使用该地址下的 /chat/completions。你可修改这条生产连接的地址，并从该连接可用的模型目录选择生产模型；在其他服务账户中添加或选择模型，不会切换正式粗剪的账户、密钥或协议。修改生产地址不会增加协议支持；其他服务是否满足现有请求、响应和剪辑要求仍须实际验证，不能把所有兼容接口或模型视为已经支持正式粗剪。

第三方数据接收方由实际操作使用的服务地址决定。使用默认官方地址时，请求交给 DeepSeek 官方服务；使用自定义地址时，请求及用于认证的 API Key 交给该地址的运营者，其可能继续转发给其他服务。自定义地址不代表 DeepSeek 官方服务，也不自动适用其条款。请向实际运营者确认接收方、保存地点和处理规则。

生成请求包含字幕文字和字幕标识，以及选定的音频停顿、静音和边界摘要（包括是否有停顿/静音、候选边界距离和置信度），并带有剪辑强度、输出语言、任务指令、模型和请求控制参数。一次生成可能包含多个并行请求、分块和重试，部分内容可能重复发送。应用不会在这条生成请求中把媒体文件、文件路径、文件访问书签或完整项目 XML 作为请求字段发送；字幕本身如含姓名等个人信息，仍会随字幕发送。请仅发送你有权处理的内容，并事先取得涉及他人个人信息的必要授权。连接也会向服务端暴露通信所需的网络信息，例如 IP 地址；服务端如何记录这些信息取决于其规则。

每次开始生成前，应用要求你同意本次数据发送。拒绝会阻止该次 AI 生成发送，且不会删除已有项目、建议或导出结果。你仍可使用不依赖 AI 的本机功能，包括在满足相应使用权限时使用字幕分段。再次生成须再次同意。拒绝生成不关闭其他网络功能，例如你主动触发的连接测试、模型刷新或 Apple 商店功能。

设置中的连接测试和刷新模型会联系当前操作所选账户的配置地址。普通 AI 设置的连接测试使用生产连接读取模型列表；大模型管理的连接验证也可能发送合成测试指令和模型参数，不发送项目字幕。自动发现仅适用于应用已实现且该预设支持的列表接口；部分服务只能手动配置模型，原生协议的连接测试也不等于正式剪辑适配。认证信息和测试内容会发给实际测试地址；这些操作不切换正式粗剪连接。

API Key

你提供的 API Key 保存在 macOS 钥匙串（Keychain）中，普通配置仅保存凭据引用。不同服务账户使用各自的本机凭据；当前生产连接使用其专用凭据，不会自动改用新添加账户的密钥。执行请求时应用在内存中读取相应密钥，并根据调用路径通过认证标头发送；当前生产路径及兼容接口使用 HTTPS 请求的 Authorization: Bearer，Anthropic 原生连接测试使用 x-api-key。自定义地址也会收到该操作使用的认证密钥。密钥不是 TalkTrim 账号，应用不以项目历史或普通偏好保存明文密钥。删除本机密钥不等于在第三方平台撤销该密钥，也不能保证已经开始的请求立即停止。第三方服务费用不包含在 TalkTrim 购买价格中。

第三方规则与已发送数据

当你使用 DeepSeek 官方服务时，请阅读 DeepSeek 开放平台服务协议 和 DeepSeek 隐私政策。其他服务适用其实际运营者的条款和隐私政策；请在配置和发送前自行确认。这些资料不能替代本应用对自身处理行为的说明。官方资料包含训练、技术改进用途及退出说明，但我们尚未确认这些说明对具体 API 输入/输出的适用方式。我们尚未核实可覆盖所有 TalkTrim API 请求的固定保留期限、不用于训练承诺或逐请求删除保证，因此不作这些承诺。DeepSeek 官方政策说明其在中国境内存储相关个人信息；对你具体 API 内容的适用范围及其他服务的数据地点，仍需向相应运营者确认。

TalkTrim 没有远程删除第三方请求的功能。对于已发送给官方服务的个人信息，你可通过 privacy@deepseek.com 提出权利请求，API 相关协助可联系 api-service@deepseek.com；请求可能需要身份核验并受适用法律和技术条件限制。这些是提出请求的渠道，并非已经完成删除的保证。自定义服务的数据请求须向其运营者提出。你也可通过上方隐私联系渠道就 TalkTrim 的处理或所需协助联系我们。取消生成、删除本机缓存或卸载应用不会自动撤回已发送内容。

Apple 商店

Apple 负责 App Store 支付流程。TalkTrim 使用 StoreKit 商品信息及经验证的试用/购买事实决定 14 天试用和一次性完整解锁权限，并在本机钥匙串保存必要的试用时间检查点。应用没有自建支付服务器，不接收你的 Apple 账号密码或支付卡号。Apple 的服务另受其 隐私政策 约束。

删除、撤回与联系

你可以在设置 → AI 与模型中选择“删除 API Key”；这只删除相应本机凭据。设置中的“恢复默认”恢复普通偏好及默认 AI 配置，不清除项目历史、文件书签、音频缓存或钥匙串密钥。大模型管理中可删除额外添加的服务账户及其相应本机凭据；生产 DeepSeek 账户本身受保护，密钥仍通过上述专用入口删除。

源项目、媒体和导出文件由你在 Finder 等文件管理工具中管理和删除。当前应用没有一键清除所有本机数据或逐条删除建议历史的入口。若需移除本机应用状态或缓存，请先退出应用，并通过隐私联系渠道获取适合你安装环境的手动清理指导。不要把恢复默认或仅将应用移到废纸篓视为已删除所有数据；钥匙串、备份及第三方副本需要分别处理。应用未承诺自动清除这些副本。

当前应用的隐私清单声明不进行追踪，未实现自建分析上报或广告服务；这不意味着第三方不会处理数据。若你主动联系我们，所提供的联系信息、问题描述和附件会进入所选支持渠道。请避免发送密钥、私人媒体或未脱敏字幕。客服资料按问题解决后保留 90 天的管理规则处理，适用法律义务及未解决争议除外；由开发者人工管理，当前没有自动清理机制。这不表示已完成任何删除，也不保证邮箱服务商的备份已彻底删除。你可通过上述邮箱查询或提出删除请求。

如对个人信息有查阅、更正、删除、撤回或其他权利请求，可通过上方隐私联系渠道提出；请求按适用法律处理，第三方副本的处理结果以相应服务的答复为准。政策发生变化时，我们会更新公开页面与日期；涉及新增发送或用途的变化须在使用前说明并依法取得所需授权。

公开页面与网站访问

公开页面托管于 GitHub Pages。GitHub 会为安全目的记录和保存访问者的 IP 地址，与你是否登录 GitHub 无关。本页面不使用广告、第三方统计脚本或主动设置 Cookie，不收集表单资料，也不建立用户数据库。托管平台仍按其规则处理访问数据；具体保留期限尚未核实，平台设置的 Cookie（如有）取决于其规则和实际响应。请参阅 GitHub 隐私声明。电子邮件服务商也可能按其规则处理邮件及备份，我们不能保证其副本已删除。
