支持范围

TalkTrim 是 macOS 应用，用于整理可审核的 Final Cut Pro 口播粗剪建议。需要 macOS 14.0 或更高版本；TalkTrim 1.0 当前支持 Final Cut Pro 导出的 FCPXML 1.14、单 Project、单 Primary Storyline、一条自带音频的主要口播视频及对应的已有字幕。不支持任意视频直接导入后全自动剪辑，不提供自动语音识别。字幕分段是处理已有字幕的独立本机功能，不调用 AI，也不自动决定删除内容。

AI 与连接

第三方 AI 模型服务由你自行配置，服务费用独立于 TalkTrim 费用。大模型管理可添加不同服务账户、HTTPS 地址、模型 ID 和 API Key，并按已实现的能力测试连接或发现模型；部分服务须手动输入模型 ID。配置、发现或连接成功不表示该服务已支持正式粗剪。

当前正式粗剪仍使用默认生产连接的 DeepSeek 协议调用路径，默认地址为 https://api.deepseek.com。可修改该生产地址并在其可用目录中选择模型；新增账户不会自动成为生产账户，也不会切换生产密钥或协议。修改地址后，其他服务能否满足现有请求/响应和剪辑要求仍须实际验证，不能保证任意兼容接口或模型可用。实际地址的运营者会收到该操作的请求和认证密钥，并可能继续转发；请核实其身份、条款和数据规则。

每次生成需要确认发送字幕文字、字幕标识、选定的停顿/静音/边界摘要、剪辑偏好与任务参数。一次生成可能有并行请求、分块和重试。原始视频/音频不作为 AI 请求上传。拒绝会阻止该次生成发送；本机导入、已有结果以及不依赖 AI 的功能不会因此被删除。其他功能仍受各自使用权限限制。

普通 AI 设置的连接测试使用生产连接读取模型列表；大模型管理中的连接验证还可能发送合成测试内容。刷新模型和测试其他账户会联系对应配置地址，并按协议发送认证信息；这些主动操作与生成授权分开，也不会切换生产连接。连接成功只提供接口层面的证据，不表示该账户已可用于正式粗剪或剪辑质量已经验证。

连接失败时，先检查服务地址、网络、API Key 是否有效及第三方账户余额。不要把密钥发给支持人员。只分享应用显示的脱敏错误代码；不要直接转发第三方原始响应。

删除与隐私请求

  • 删除本机生产 AI 密钥：设置 → AI 与模型 → 删除 API Key。第三方平台上的撤销需另外操作；已经开始的请求不会因删除密钥而保证停止。
  • 恢复默认只恢复普通偏好及默认 AI 配置，不删除项目历史、书签、缓存或 Keychain 密钥。
  • 额外添加的服务账户可在大模型管理中删除；生产 DeepSeek 账户受保护，其密钥用专用入口删除。
  • 源项目、媒体与导出文件由你在 Finder 等工具中删除。应用没有一键清除全部本机数据或逐条删除历史的入口；需手动清理应用状态/缓存时，请先退出应用并联系隐私渠道取得适合当前安装的指导。卸载不代表所有数据、Keychain 或备份已经清除。
  • 对已发送给 DeepSeek 官方的个人信息，可向 privacy@deepseek.com 提出权利请求；API 协助联系 api-service@deepseek.com。自定义服务须联系其运营者。TalkTrim 不能直接远程删除这些数据，且不保证第三方请求一定获准或已删除。

试用与购买支持

TalkTrim 提供 14 天完整功能试用和一次性完整解锁，无订阅或自动续费。Apple 负责购买及恢复购买流程。若遇商店问题，请提供显示的错误代码并联系支持；不要发送 Apple 密码、支付卡资料或完整交易凭证。

联系时提供什么

请提供 TalkTrim、macOS、Final Cut Pro 版本、失败步骤及脱敏错误代码。请先遮盖截图中的个人资料、项目名、文件路径和账户信息。不要发送 API Key、密码、私人媒体、完整字幕或未脱敏 FCPXML。如确需样例，先确认内容权利与最少资料范围。支持沟通会进入你选择的支持渠道。

客服资料按问题解决后保留 90 天的管理规则处理，适用法律义务及未解决争议除外；由开发者人工管理，没有自动清理机制。这不表示已完成任何删除，也不保证邮箱服务商备份已彻底删除。可通过上述邮箱查询或提出删除请求。我们不承诺固定回复时限。
