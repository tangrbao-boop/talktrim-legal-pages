支持范围

TalkTrim 是 macOS 应用，用于整理可审核的 Final Cut Pro 口播粗剪建议。需要 macOS 14.0 或更高版本；TalkTrim 1.0 当前支持 Final Cut Pro 导出的 FCPXML 1.14、单 Project、单 Primary Storyline、一条自带音频的主要口播视频及对应的已有字幕。不支持任意视频直接导入后全自动剪辑，不提供自动语音识别。字幕分段是处理已有字幕的独立本机功能，不调用 AI，也不自动决定删除内容。

AI 与连接

第三方 AI 模型服务由你自行配置并使用自己的 API Key，费用独立于 TalkTrim。大模型管理可添加不同服务账户，并按已实现的能力测试连接或发现模型；部分服务须手动输入模型 ID。配置、发现或连接成功，不表示该服务已支持正式粗剪或剪辑质量已经验证。

正式粗剪可继续使用原有 DeepSeek 连接，默认地址为 https://api.deepseek.com；也可明确选择已适配的阿里云百炼账户与 qwen-plus。当前新增生产接入仅限百炼 qwen-plus，不代表其他服务商、其他模型或所有复杂工程已经可用。DeepSeek 在服务列表中与其他服务平级，其已有用户仍可使用专用密钥入口。

  • 在设置 → AI 与模型 → 大模型管理中选择服务并新增账户。百炼需选择与你的账户及 Key 对应的地域；确认 HTTPS 地址，录入自己的 Key，保留或添加 qwen-plus 后保存。专属或自定义地址须核对实际运营者。
  • 在“正式粗剪使用的账户与模型”中明确选择这个账户与 qwen-plus。只新增、保存、刷新或测试账户，不会自动改选正式粗剪账户。
  • 需要使用 DeepSeek 时选择该内置连接，并在其专用区域管理密钥；其他账户的 Key、连接测试与地址在对应账户中管理。修改地址不会自动增加协议支持。
  • 实际地址的运营者会收到请求和认证 Key，并可能继续转发；请先核实身份、费用、条款和数据规则。

每次生成前，核对确认界面中的账户、模型及接收地址主机信息；完整地址可到对应设置中核对。确认会发送字幕文字、字幕标识、选定的停顿/静音/边界摘要、剪辑偏好、任务及请求参数，必要时包括派生中间剪辑计划和修订上下文。一次生成可能有并行请求、分块和受限重试。原始视频、音频及完整 FCPXML 不作为 AI 请求内容上传。拒绝会阻止该次生成发送，不删除已有本机项目或结果。再次生成须重新确认；其他功能仍受各自使用权限限制。

DeepSeek 专用连接测试读取该内置连接的模型列表；其他账户的连接验证还可能发送合成测试内容。刷新模型和测试账户会联系对应配置地址，并按协议发送认证信息；这些主动操作与生成授权分开，也不会自动改选正式粗剪账户。连接成功只提供接口层面的证据，不等于粗剪完成或剪辑质量通过。

失败后应用不会静默切换其他账户或服务商。请检查地址、地域、网络、Key 有效性和第三方账户余额；若所选账户/模型已删除、缺少 Key 或尚未适配，请先修正配置并重新选择。网络请求可能按受限规则重试；取消不保证撤回已发送内容。不要把密钥发给支持人员。只分享应用显示的脱敏错误代码，不要直接转发第三方原始响应。

删除与隐私请求

  • 删除内置 DeepSeek 本机密钥：设置 → AI 与模型 → DeepSeek 专用“删除 API Key”。其他账户在大模型管理的对应账户中删除密钥；第三方平台撤销须另外操作，删除本机 Key 不保证已开始请求停止。
  • 恢复默认恢复普通偏好及默认 AI 配置，并选回内置 DeepSeek；保留额外账户及 Keychain 密钥，不删除项目历史、书签或缓存。
  • 额外账户可在大模型管理中删除，同时删除该账户的本机密钥；密钥删除失败时保留账户供重试。内置 DeepSeek 账户本身受保护，其密钥仍可用专用入口删除。若删掉当前选中的账户或模型，需重新选择有效配置。
  • 源项目、媒体与导出文件由你在 Finder 等工具中删除。应用没有一键清除全部本机数据或逐条删除历史的入口；需手动清理应用状态/缓存时，请先退出应用并联系隐私渠道取得适合当前安装的指导。卸载不代表所有数据、Keychain 或备份已经清除。
  • 对已发送给 DeepSeek 官方的个人信息，可向 privacy@deepseek.com 提出权利请求；API 协助联系 api-service@deepseek.com。百炼用户请使用账户适用的官方服务及隐私渠道，自定义服务须联系实际运营者。TalkTrim 不能远程删除这些数据，不保证第三方请求一定获准或删除完成。

试用与购买支持

TalkTrim 提供 14 天完整功能试用和一次性完整解锁，无订阅或自动续费。Apple 负责购买及恢复购买流程。若遇商店问题，请提供显示的错误代码并联系支持；不要发送 Apple 密码、支付卡资料或完整交易凭证。

联系时提供什么

请提供 TalkTrim、macOS、Final Cut Pro 版本、失败步骤及脱敏错误代码。请先遮盖截图中的个人资料、项目名、文件路径和账户信息。不要发送 API Key、密码、私人媒体、完整字幕或未脱敏 FCPXML。如确需样例，先确认内容权利与最少资料范围。支持沟通会进入你选择的支持渠道。

客服资料按问题解决后保留 90 天的管理规则处理，适用法律义务及未解决争议除外；由开发者人工管理，没有自动清理机制。这不表示已完成任何删除，也不保证邮箱服务商备份已彻底删除。可通过上述邮箱查询或提出删除请求。我们不承诺固定回复时限。
